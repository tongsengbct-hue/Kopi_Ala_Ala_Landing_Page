# Kopi Ala Ala — Landing Page UMKM

Landing page kedai kopi dengan gaya **Modern Premium**, palet cokelat kopi dan krem. Dibangun menggunakan HTML5, CSS3, JavaScript vanilla, dan Bootstrap 5. Tidak membutuhkan database maupun backend.

## Isi folder
- `index.html` — struktur dan konten halaman.
- `css/style.css` — palet warna, tipografi, layout, dan responsive styling.
- `js/script.js` — tahun otomatis, navigasi mobile, dan efek navbar.
- `images/` — ilustrasi SVG lokal untuk hero, menu, dan suasana kedai.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `kopi_ala_ala_landing_page`.
3. Klik dua kali `index.html`, atau jalankan Live Server dari VS Code.
4. Pastikan koneksi internet tersedia untuk memuat Bootstrap 5 CDN dan Google Fonts. File gambar tetap tersedia secara lokal.

## Kustomisasi sebelum dipublikasikan
- Ubah nama, deskripsi, harga, dan daftar menu di `index.html`.
- Ganti alamat kedai, jam operasional, dan nomor WhatsApp pada bagian Kontak. Nomor saat ini hanya contoh (`6281234567890`).
- Ganti ilustrasi di folder `images/` dengan foto produk/kedai asli. Pertahankan nama file atau sesuaikan `src` di HTML.
- Untuk mengubah warna, edit variabel CSS di bagian `:root` pada `css/style.css`.

## Teknologi
HTML5 · CSS3 · JavaScript · Bootstrap 5.3.3 · Google Fonts

## Catatan
Harga dan detail usaha yang tampil adalah konten contoh untuk kebutuhan demo, bukan informasi operasional yang telah diverifikasi.
